### 🚀 What I've been building

**🖥️ Proxmox Home Lab**
One Proxmox host running a VM and around ten Linux containers: Jellyfin media, AMP game-server hosting, a UniFi network controller, Docker, a WireGuard VPN and a Homarr dashboard tying it all together.

**🌐 VPS Front Door for the Lab**
A Debian VPS that publishes home-lab services **without exposing my home IP or opening router ports**:
- WireGuard site-to-site tunnel from the lab to the VPS
- Caddy reverse proxy behind Cloudflare for websites (web ports only accept Cloudflare)
- iptables port forwarding for game servers
- Key-only SSH, no password logins

<sub>This is what serves <a href="https://router-racer.com">router-racer.com</a> right now.</sub>
